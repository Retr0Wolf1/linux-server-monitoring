# Linux Server Monitoring

Monitoring infrastructure using:

- Prometheus
- Grafana
- Node Exporter
- SNMP Exporter
- Alertmanager

## Architecture

MikroTik
   |
  SNMP
   |
SNMP Exporter
   |
Prometheus
   |
Grafana


## Features

- Linux server monitoring
- MikroTik monitoring
- CPU/RAM/Disk metrics
- Network traffic monitoring
- Alerts
- Grafana dashboards


## Installation

Run:

./scripts/install-all.sh
